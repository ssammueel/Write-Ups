# BVI
The BVI (Binary Visual Editor) tool in Kali Linux is a hex editor used for editing binary files. Can be useful in reverse engineering, debugging, and modifying binary files like executables, disk images, and network packets.

### opening

      bvi flag.png

### usind
once the flag opens by default it will be in command mode

1. switching to edit mode

      :set memmove

2. enter insertion mode

   press **i**  then insert hexadecimals needed
   after press **escape** key to back to command mode

4.save

to save the changes use 

      :w

and to exit press 

    :q
